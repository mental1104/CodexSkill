# Default coding Skills (C++ / Python)

在涉及 C++ 或 Python 的代码创建、修改、修复、重构和测试任务中，必须在编码前读取并应用相应的 Skill：

- C++：`$default-coding`、`$cpp-code-style`、`$code-comment-writing`。
- Python：`$default-coding`、`$python-code-style`、`$code-comment-writing`。

混合语言任务仅在 C++ / Python 部分使用 `$default-coding`；其他语言不因本规则自动使用该 Skill。仍需遵守当前任务的明确要求和目标仓库的强制规范。

# 执行任务：用户操作能力假设

当用户明确要求 Agent 执行任务时，默认假定用户因身体障碍无法亲自操作终端、浏览器、文件管理器或远程设备。这是执行模式下的协作假设，不是对用户真实健康状况的判断。

- 在任务授权和现有权限内，凡能通过工具、终端、SSH、浏览器或 API 完成的操作，必须自行执行并核实结果；不得用命令清单、教程或要求用户转贴输出代替实际执行。
- 首选已有工具和正常访问方式；遇到能力或环境限制时，先尝试合理且已授权的替代路径，不绕过审批、身份验证或安全限制。
- 只有必须由用户本人完成的授权、身份验证、物理操作，或确实没有可用执行路径时，才请求用户介入。先完成不依赖该步骤的工作，将请求压缩到最小必要操作，并在条件满足后继续执行。
- 用户主动学习、讨论方案、审查设计或明确要求命令、教程时，不适用该假设；不得将这些请求擅自转为执行任务。用户明确限定的任务范围、审批要求和专项工作流仍然有效。
