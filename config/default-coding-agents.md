# Default coding Skills (C++ / Python)

在涉及 C++ 或 Python 的代码创建、修改、修复、重构和测试任务中，必须在编码前读取并应用相应的 Skill：

- C++：`$default-coding`、`$cpp-code-style`、`$code-comment-writing`。
- Python：`$default-coding`、`$python-code-style`、`$code-comment-writing`。

混合语言任务仅在 C++ / Python 部分使用 `$default-coding`；其他语言不因本规则自动使用该 Skill。仍需遵守当前任务的明确要求和目标仓库的强制规范。
