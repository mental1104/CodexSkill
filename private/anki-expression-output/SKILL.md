# Anki Expression Output

## Core Concept

Use this skill for the user's English expression workflow:

```
complete sentence -> usage appreciation -> atomic expression unit -> Chinese trigger -> personal example -> AI practice task -> Anki output practice
```

Treat `atomic_unit` as a reusable expression structure, phrase, collocation, discourse marker, or sentence frame. Do not turn the system into vocabulary cards or ask the user to memorize source sentences. Source sentences provide context; `atomic_unit` is the output target.

## Expected TSV Schema

Prefer a TSV like `sentence_usage_analysis.tsv` with these fields:

- Required for import: `trigger_zh`, `atomic_unit`, `sentence`, `sentence_function`, `appreciation_zh`, `personal_example`, `practice_task`, `unit_type`, `source_filename`, `source_line`, `confidence`, `needs_review`, `review_reason`, `source_path`, `tags`
- Generated by import script: `import_id`, `tags_source`

If a required field is missing, stop and report the missing fields. Do not invent note content silently.

## Anki Defaults

Use these defaults unless the user asks otherwise:

- Note type: `Sentence Usage Atomic Unit`
- Main deck: `English::Expression Output`
- Review deck: `English::Expression Review`
- `needs_review=false` -> main deck
- `needs_review=true` -> review deck
- Two card templates per note:
  - `Output - Trigger to Expression`: front shows `trigger_zh`; back shows `atomic_unit`, personal example, source sentence, and appreciation.
  - `Context - Sentence to Unit`: front shows `sentence`; back shows `atomic_unit`, function, trigger, and practice task.

Use Anki tags from the TSV `tags` column by converting semicolon-delimited tags into Anki tag tokens. Add import tags such as `anki_import::sentence_usage_analysis`, `needs_review::true/false`, and `unit_type::<unit_type>`.

## AnkiConnect Address

Before importing or editing templates, test AnkiConnect. Default desktop Anki is usually `http://127.0.0.1:8765`. For WSL2 when Anki runs on Windows, use the Windows host IP, for example `http://172.29.240.1:8765`.

If sandboxing blocks localhost/host networking, rerun the exact needed command with `sandbox_permissions="require_escalated"` and a clear local-AnkiConnect justification.

## Import Workflow

Use `scripts/import_sentence_usage_to_anki.py` for deterministic import.

```bash
python3 /home/mental1104/.codex/skills/anki-expression-output/scripts/import_sentence_usage_to_anki.py   --tsv Archive/300-Language/310-English/sentence_usage_analysis.tsv   --anki-url http://172.29.240.1:8765
```

The script verifies AnkiConnect, creates output/review decks, reuses or creates a compatible note type, imports without duplicates, and reports added/skipped/failed notes. Do not modify TSV rows during import. Keep note content and card template changes separate.

## Template Workflow

Use `scripts/update_sentence_usage_template.py` to add or refresh the card templates for ChatGPT feedback.

```bash
python3 /home/mental1104/.codex/skills/anki-expression-output/scripts/update_sentence_usage_template.py   --anki-url http://172.29.240.1:8765   --backup-dir Archive/300-Language/310-English/anki
```

The updater must:

1. Verify required fields: `import_id`, `trigger_zh`, `atomic_unit`, `personal_example`, `sentence`, `appreciation_zh`.
2. Back up model name, fields, templates, and styling before changes.
3. Modify only templates/styling, not note field data.
4. Keep the front free of `atomic_unit`.
5. Add a `My answer` textarea to the front of `Output - Trigger to Expression`.
6. Save the answer locally by `import_id`, not as an Anki field.
7. Add a back-side `Copy for ChatGPT` button and `Manual copy text` fallback.
8. Copy `my_answer`, `trigger_zh`, `atomic_unit`, `personal_example`, `sentence`, and `appreciation_zh`.
9. Prefer inline `onclick` logic over a separate `<script>` block for Anki WebView reliability.
10. Use fallbacks: `navigator.clipboard.writeText`, temporary textarea plus `document.execCommand('copy')`, then visible selected textarea.
11. Use `String.fromCharCode(10)` for newlines inside inline JavaScript.
12. Write before/after backups and a unified diff.

## Review Guidance

When advising the user how to study:

- Prioritize `English::Expression Output`.
- Treat `English::Expression Review` as a screening deck; suspend items that are too course-like, private, unnatural, or not personally reusable.
- Score by active output, not recognition: Again cannot produce; Hard recognizes after seeing; Good produces close expression; Easy produces quickly and can make a new sentence.
- Encourage weekly writing practice using recently learned `atomic_unit` items.

## Safety

Always back up Anki templates before editing. Never change note fields or delete notes unless explicitly asked. If template fields are missing or have case mismatches, stop and ask the user to confirm the target model/field names.
